# U3 测试说明

## 测试框架与配置

使用 Node 内建 `node:test` 与现有文档链接解析函数，不安装新依赖。

## 本单元命令

从仓库根目录执行：

```powershell
node --test scripts/checks/test-technology-guide.mjs
```

该命令只运行 U3 的 5 项测试。全仓 `node scripts/check-docs.mjs` 和既有文件地图测试在完成后另行运行，分别检查链接及新文件是否被纳入清单。

## 预期覆盖与边界

测试检查技术分区、与源码/配置的本地链接、教学比较标签、AI-DLC 与网站运行时的边界、阅读入口与文件清单；不把文本关键词检测当作事实核实。实际技术判断需人工对照相应文件。没有运行 AWS 服务、付费模型采样、容器或线上部署；本单元没有可测量的应用代码行覆盖率。
