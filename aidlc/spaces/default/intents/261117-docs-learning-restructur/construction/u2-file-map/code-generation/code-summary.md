## 文件变化

- 新建 `docs/learning/file-map.md`：零基础目录导览、项目手写与生成文件分类、规则入口和地图更新办法。
- 新建 `docs/learning/file-map-inventory.md`：以 2026-11-23 本机 Git 可见范围为基准，逐项记录 311 个项目自写文件的路径、功能、用途与修改时机；依赖锁文件、AI-DLC 安装/运行树、日期证据按类别解释。

## 实施决定

地图分两层：短页解释文件夹和类别，长页供逐路径查找。逐文件清单不声称已经验证实时 AWS，也不读取私有或被忽略文件。`outputs/` 作为带日期证据按类别说明。以后新增或移动项目自写文件，应同步更新清单并运行覆盖测试。

## 检查结果与边界

- `node --test scripts/checks/test-file-map.mjs`：5 项通过。
- `node scripts/check-docs.mjs`：退出 0；实施者初跑检查 367 份，总结写入后检查 368 份，审阅后的补充复测检查 369 份项目 Markdown 的本地链接目标。
- `git diff --check`：退出 0。

没有运行前端/后端构建、容器、浏览器、真机、AWS STG 或生产检查；本单元只修改文档与定向测试。自动测试证明清单路径覆盖和链接存在，具体“用途”仍须读者按被指向文件人工核对；没有把这些语义解释写成自动验证结论。
