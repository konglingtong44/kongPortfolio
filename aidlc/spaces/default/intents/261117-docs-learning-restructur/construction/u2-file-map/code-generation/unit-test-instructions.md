# U2 测试说明

## 测试框架与配置

使用 Node 内建 `node:test`，复用项目现有文档链接检查函数和 Git 文件列表；不新增依赖或改动测试配置。

## 本单元命令

从仓库根目录执行：

```powershell
node --test scripts/checks/test-file-map.mjs
```

仅运行 U2 的 5 项定向测试。完成后另运行项目既有 `node scripts/check-docs.mjs` 检查所有项目 Markdown 的本地目标；它是全仓验证，不算本单元专属测试命令。

## 覆盖、输入与边界

测试至少覆盖：版本管理中项目手写文件的清单覆盖、清单路径存在、生成文件分类、U1 到地图的导航、地图本地链接。测试只读取 Git 列表及仓库公开文件，不访问网络或 AWS，也不读取 `.env`、证书、Terraform state 和个人资料。没有有意义的应用代码行覆盖率指标；是否读懂文件用途须通过人工对照文件内容判断，自动化测试不冒充语义审阅。
