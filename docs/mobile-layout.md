# 手机布局与项目手势

保留桌面主体布局；手机调整布局与交互，桌面左侧时间线支持鼠标拖动。

验收：

- 手机通过底部四个章节入口切换；页面保留原生上下滚动，远距离章节直接定位。
- 手机 01 默认展示三行介绍和折叠的学习／任职经历，可分别展开完整内容；按可用高度适配，大屏限制额外留白。390×844 模拟下，首屏含顶栏约 712px，02 约 708px。
- 章节边界采用 proximity 轻吸附；03 保持长内容的自然滚动，小屏／横屏不强行裁成一屏。
- 第二块左侧时间线独立上下滚动；点击只定位项目，不自动弹详情。
- 右侧左右滑动切换项目，上下滑动继续浏览第三块；点击卡片才打开详情。
- 横竖屏切换保留当前项目；处理底部安全区、窄屏文字和弹窗高度。
- 桌面按住左栏上下拖动可浏览时间线，拖动结束不触发点击；项目切换后时间线继续跟随当前项目。
- 时间线连接线随各条经历滚动，只连接到下一节点，不在末尾留尾线。
- 手机点击架构图节点弹出悬浮说明；同点再次点击、点空白或滚动图面关闭。气泡位于弹窗顶层，按屏幕和弹窗边界限宽、限高。

验证：64 项前端测试与生产构建；Chromium 检查鼠标拖动、点击和触摸滚动。WebKit 检查 320–430px 竖屏与 844px 横屏、简介展开、经历展开、03 内部滚动、时间线定位、弹窗和章节导航；三张架构图共 18 次气泡显示／关闭检查。桌面简介、项目、技术区截图与本次压缩前逐字节一致。

浏览器设备模拟不等于 iPhone 真机验收。未修改后端，未部署 AWS。
