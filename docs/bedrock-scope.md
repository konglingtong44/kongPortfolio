# 问答范围：自然提问与一次语义判断

2026-11-15本地实现，待评审／未发布。线上生产23仍是旧严格问句白名单；旧验收记录见[发布复核](bedrock-typed-release.md)与[11月14日操作](aws-commands-20261114.md)。用户明确接受语义判断带来的拒绝调用费，以避免相关问法反复被误拒绝。

## 现在的边界

`参数校验 → 并发／频率限制 → 固定版本资料 → 边界提示＋资料＋访客原始问题 → Qwen一次决定并作答 → Java严格校验JSON → 返回`

- 允许自然询问孔令通的经历、技能、学历／资格、项目、职业方向和做事方法，包括需求定义、设计、技术调查、测试和协作；理解口语、换句话问及笔误。
- 本人相关但缺少事实的问题仍属于范围内，简短说明尚未确认，不推测转职动机、资格有效性或项目职责。
- 无关聊天、通用解题／代码生成、私人联系方式／雇主实名、规则绕过、修改／记忆个人事实，以及夹带这些任务的混合请求，要求模型拒绝。
- Java不维护问句匹配表。GET目录的18个三语示例用于填入编辑，不限制其他说法；打开和点示例都不生成回答。

## 返回与保护

策略版本`portfolio-semantic-v2`。模型只返回两个字符串字段`decision`和`answer`；决定仅ANSWER／REFUSED。无效JSON、重复字段、尾随内容、错误字段或截断不展示，返回502且不自动再调用。REFUSED使用服务端三语固定提示，不回显模型拒绝正文。成功和拒绝均为`modelInvoked=true`并附实际usage，不能沿用旧版0 tokens的报告。

Java继续限制规范URL、8KiB、1,000码点、仅message／language、日中英、实例内1并发／6每分钟／60每小时；模型HTTP／输出上限及API Gateway既有限流保持。实例内配额不是全站共享计数。空POST／功能关闭仍PREPARING；无效请求、超限或资料失败可在模型前结束。

只使用原私有S3审核版本；职业事实与历史政策说明分离，排除已过期的Q&A未公开备注。对话只包含本次问题，不写S3、文件、会话记录或知识库；访客断言不会成为下次的资料。应用访问日志及安全报告不记录问答／履历正文。此边界约束Java入口，不能约束管理员的其他授权入口。

## 成本与验证

不创建知识库、向量库、Embedding、独立分类器或收费Guardrails；**拒绝也有模型输入和输出费**。缓存只减少S3读取，不减少每次模型输入tokens。具体费用和测试见[自然问答增量](bedrock-natural-questions.md)及[当日命令](aws-commands-20261115.md)。

提示词决定语义范围，Java检查结构而非证明每句事实。样本通过不代表所有问法均无误判／幻觉；如需更强保证，应评估额外证据验证和费用。旧白名单的确定性零模型拒绝保证已经由用户选择的新方式取代。
